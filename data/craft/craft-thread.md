# مستشار البنية — الثريد

> مقطَّر يدوياً من `SPEC-2` v1 (مختبر أسلوب خارجي) — **بنية وحركات فقط**: قواعد السجل اللغوي مستبعدة عمداً (سيادة الصوت لمحرّك التوليد). يُحدَّث يدوياً عند تغيّر المصدر.

## قرارات المعمار (قبل الكتابة)

- **قطبية الطول:** إما **كبسولة** (جزء حامل بحمولة مكتملة + جزء وظيفي قصير) حين تكون الحمولة أصلاً جاهزاً، وإما **سُلَّم طويل** بعدد مغلق من الدرجات حين تكون منهجاً معدَّداً — **لا بناء بين القطبين**.
- **شوكة الخزنة/الساحة:** الخزنة = وعد أصل معدود + الأصل **كاملاً في الجزء الأول** + إغلاق بأمر استهلاك (صفر سؤال). الساحة = رأس ≤ 4 كلمات (حكم/مفارقة) + وسيط حامل + صفر شرح مصاحب.
- **القاعدة السالبة المركزية:** كل جزء مكتفٍ بذاته — **صفر أدوات جسر**: لا عدّاد أجزاء، لا «وفي الجزء التالي»، لا سؤال انتقالي، لا سطر تشويق بين الأجزاء.

## وعد الافتتاح (الرأس)

- **عقد الرأس:** وعد قدرة موجَّه للقارئ (فعل أمر أو «كيف» + مضارع) + مفعول معيَّن + مكمِّم (عدد/مدة/كلفة-صفر) — **بلا ضمير متكلم** ← مفصل ترقيمي ← الحمولة.
- **الرأس عنواناً لمرفق:** جملة وعد ≤ ~190 حرفاً + نقطتان ← التسليم داخل المنشور الأول نفسه؛ الرابط إن وُجد يُعزل في الجزء الثاني شبه عارٍ.
- **تعيين مفعول الوعد:** وعد بعدد مغلق N ← N درجة مرقمة **تطابقاً تاماً** ← استعادة N في الإغلاق.
- **تسمية الوعد بالنتيجة** التي يبلغها القارئ لا باسم الأداة/النظام — وإعادة إصدار نفس الوعد لاحقاً بإطار مغاير وفاصل أيام.
- **تشخيص خطأ الأغلبية ثم القلب:** ممارسة معكوسة لدى فئة محددة ← قلب فوري ← بقية الثريد تصحيح مرقَّم بحد مغلق.
- **إغلاق الجزء الأول بحكم قاطع** ≤ سطرين (أو أمر + مدى زمني) — صفر أدوات احتمال.

## ما بين الأجزاء

- **كبسولة النبضتين:** كل جزء = حمولة مكتملة + ذيل وظيفي قصير — والجزء الثاني في الكبسولة ≤ ~240 حرفاً بوظيفة واحدة (توزيع/وصول/إسناد) وصفر معنى جديد.
- **الدرجة النموذجية في السُلَّم:** اسم العنصر + وظيفته بسطر + ثلاث قدرات بشرطات + كتلة قابلة للنسخ + سطر عاقبة معزول — **قالب متماثل يحمله العدّ** (الاحتفاظ بالإكمال لا بالتوتر).

## تموضع الذروة

- **تصفير الطيّة:** الذروة في الموضع الأول ولا يُؤجَّل إلا الوصول — أو —
- **ختام السُلَّم:** ذروة تركيبية عند ~85% من الطول (تركيب جامع + موجّه) ثم ذيل هابط (منع/قياس/ما-بعد) ← أفق تجريدي ← خلية نداءات.

## الإغلاق

- **تحريم المحتوى على الخانة الأخيرة:** آخر جزء بطاقة ذيل ثابتة (وجهة مملوكة + رابط + علامة توجيه) أو رابط المورد وحده — **صفر جملة عن الموضوع**.
- **كلفة النداء:** جسد الثريد خالٍ من أي طلب ← علامة حدّ لفظية ← نداءات مكدَّسة تصاعدياً (خفيف ← أوسط ← أثقل ← توجيه خارجي).
- **هندسة زر الحفظ:** إغلاق مغلق (أمر استهلاك/رابط) + أمر أرشفة داخل خانة الوعد — صفر سؤال مفتوح.
- **نبضة الإسناد:** حين يُبنى على أصل منقول: الجزء الأول وعد النتيجة + الأصل، والجزء الثاني إفشاء المصدر وسياق العثور والرابط — الإسناد بدل النداء.
- **خانة الذيل متغيّر حملة:** نصها ثابت حرفياً ويُبدَّل دفعةً بتحول الهدف — لا يعاد تأليفها كل ثريد.
