## قواعد التشغيل

- استنتج الجمهور والهدف والبنية تلقائياً من المنشور — لا تسأل أحداً (جلسة آلية).
- `FINAL` واحد: صورة واحدة 16:9 بأبعاد 2560×1440.
- HTML/CSS مع SVG للعلاقات والأيقونات؛ كل النصوص طبقات حقيقية `lang="ar" dir="rtl"` — لا عربية داخل صور نقطية، لا Emoji، لا CDN ولا أي مورد شبكي.
- **الخطوط على هذا الخادم (لينكس):** استخدم `"Noto Naskh Arabic"` أو `"Noto Kufi Arabic"` أو `"Noto Sans Arabic"` مع تعاقب آمن (`sans-serif`) — لا Tahoma/Arial (غير مثبتة هنا).
- لا تخترع رقماً أو خاصية أو مصدراً — الموجود في المنشور يكفي، والمحذوف خير من المخترع.

## سير العمل (كل المخرجات في {{WORKSPACE}})

1. **حلّل واختر بنية** ← `analysis.json` (core_claim، relationship من الأنواع التسعة، ثلاثة اتجاهات داخلياً واختيار موزون — كما في المرجع).
2. **اقفل النسخة** ← `locked-copy.json` (records بمفاتيح ثابتة، 90–180 كلمة غالباً، facts_preserved، latin_terms). بعده لا تتغير كلمة ظاهرة إلا بتحديث الملفين معاً.
3. **ابنِ** ← `design.html` من السقالة أو بنية أصلية بنفس القواعد: `data-canvas` بأبعاد الإخراج، `data-copy-id` لكل نص ظاهر مطابقاً للنسخة المقفلة، `data-qa-text` للفيضان، `data-qa-box` + `data-qa-group` للبطاقات النظيرة، `data-ltr` للاتيني المعزول فقط، والتدفق من اليمين لليسار وتحقق من رأس كل سهم.
4. **صدّر** (المتغير `X_VISUAL_NODE_MODULES` مضبوط في بيئتك):
   ```
   node {{SKILL_DIR}}/scripts/render_visual.js --input {{WORKSPACE}}/design.html --output {{WORKSPACE}}/final.png --width 2560 --height 1440
   ```
5. **افحص آلياً:**
   ```
   node {{SKILL_DIR}}/scripts/qa_visual.js --input {{WORKSPACE}}/design.html --copy {{WORKSPACE}}/locked-copy.json --png {{WORKSPACE}}/final.png --report {{WORKSPACE}}/qa-auto.json
   ```
   يجب: `fatalErrors` فارغة و`score >= 90`. فشلٌ ← أصلح HTML أو النسخة وأعد 4–5.
6. **راجع بصرياً:** اقرأ `final.png` و`thumbnail-40.png` و`thumbnail-20.png` بعينك (أداة القراءة تعرض الصور): العربية حرفاً حرفاً، اتجاه الأسهم، التداخل، عمل العناوين عند 40% و20%. اكتب `qa-report.md` بأوزان المرجع وبدرجة نهائية صادقة — قيّم المرئي لا النية.
7. درجة < 90 أو خطأ قاتل ← عدّل وأعد 4–6. بعد محاولتين فاشلتين بسّط المحتوى أو البنية بدل تصغير الخط. **لا تعلن نجاحاً بدرجة غير مجتازة.**
